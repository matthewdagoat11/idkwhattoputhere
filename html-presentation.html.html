Headings

To make a heading in HTML, you'll want to use h1, h2, h3..., h6 to make a heading.
But don't just add h1 for a heading, you'll have to add < and > in between like this,
<h1>. Once you've done that, you will have add an ending bracket like this,
<h1></h1> Now you have learned to make a simple heading for your website!
<h1>Hello World!</h1>
